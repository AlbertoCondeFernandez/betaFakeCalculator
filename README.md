# betaFakeCalculator
Aplicación creada con Android Studio usando kotlin y Jetpack Compose

Integración de Firebase y Firestore (NoSQL)

Compatibilidad con Android 7.0 , API 24 en adelante

Código secreto ===1234



Consiste en una aplicación de mensajería con interfaz de calculadora falsa, que incluye un sistema de autenticación mediante correo electrónico válido y recuperación de contraseña. El acceso a la funcionalidad avanzada se realiza mediante un código secreto introducido en la calculadora ===1234, que activa un cambio de estado visual en la interfaz. La aplicación permite el envío y recepción de mensajes entre usuarios, la visualización de contactos y conversaciones compartidas, cambiar el aspecto a la calculadora mediante temas, así como la creación y edición de notas o agendas de texto sincronizadas en la nube mediante Firebase y Firestore.

Además, incorpora un botón de pánico que mantiene la sesión permitiendo mantener al usuario autenticado y evitar tener que iniciar sesión nuevamente, así como un sistema de cierre de sesión para finalizar de forma segura la autenticación del usuario.

El proyecto se planteó como una agenda privada y discreta, camuflada bajo la vista de una calculadora.
